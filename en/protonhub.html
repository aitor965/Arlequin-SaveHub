ProtonHub

Linux only (preview) Download and manage your Proton versions to play your Windows games on Linux.

ProtonHub downloads GE-Proton (the latest or the version you pick) into Steam's folder, where Steam, Heroic and GameHub can see it, and checks that it downloaded completely.

It shows how much space each Proton takes and which games use it (in GameHub, Steam and Heroic), so you can safely delete the ones nobody uses. It also tidies the prefixes in ~/Games/umu: rebuild the one of a game that misbehaves (with a SaveHub backup first) or delete the ones that no longer belong to any game.

How to use it

  • ProtonHub is in the sidebar, under Hubs (Linux only).
  • “Download” gets the latest GE-Proton, or pick another version from the list.
  • If a game has no Proton, its page takes you to ProtonHub.
  • Free, also in the Free version.
