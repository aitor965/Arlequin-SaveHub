✦ 安装

一分钟就绪

下载

从 GitHub 上的官方发布页面下载 Arlequin-GameHub-Setup.exe。

打开

由于尚未签名，Windows 可能会提示你：点击更多信息 → 仍要运行。

检查你的列表

第一次运行时，它会按商店列出找到的游戏，方便你移除不是游戏的项目。

开始游戏

选择存档备份的保存位置，如果你愿意，还可以连接你的云盘。此后它会自动更新。

系统要求：64 位 Windows 10 或 11。如需卸载：Windows 设置 → 应用 → Arlequin GameHub。你的存档备份会保留在原文件夹中。

✦ 常见问题

大家经常问的问题

真的免费吗？

是的。ArlequinFree 永久免费且无广告。ArlequinPro 推出后将是可选的。区别见 Free 和 Pro。

它会索要我的 Steam、Epic……密码吗？

不会，永远不会。GameHub 读取你电脑上已有的游戏，并用各自的启动器打开每个游戏。至于云盘，你需要在 Google、Microsoft 或 Dropbox 的官方页面上登录，GameHub 看不到你的密码。

Windows 提示无法识别该程序

在 GameHub 尚未签名期间，这是正常的。点击更多信息 → 仍要运行。

为什么找不到某个游戏？

点击“查找游戏”让它重新检查你的商店。如果是没有启动器的游戏，可以用“添加游戏”添加，或者在 选项 → 游戏库 中告诉它你存放独立游戏的文件夹。

为什么找不到某个游戏的存档？

数据库才刚刚起步。你可以在游戏详情页中手动添加文件夹，或者直接玩：GameHub 会学会它的存档位置；如果你选择分享，其他人的电脑也能自动找到该游戏的存档。

它会收集哪些数据？

只有在你开启“帮助改进 Arlequin”时才会收集：存档路径、你电脑的硬件，以及（如果你测量了 FPS）你的游戏数据摘要，始终是匿名的。在 选项 → 隐私和数据 中你可以选择分享什么。详情见隐私政策。

HUD 或准星在某个游戏中不显示

将游戏设置为无边框/窗口化全屏或无边框窗口（在独占全屏模式下不会显示），检查是否为该游戏开启了它们，以及是否用 Ctrl+Alt+H 或 Ctrl+Alt+X 将其隐藏了。

HUD 中的温度显示为“—”

这些数据需要打开一个传感器程序：HWiNFO（开启“Shared Memory Support”，免费版每 12 小时会关闭一次）、LibreHardwareMonitor（开启其 Remote Web Server）或 MSI Afterburner。HWMonitor 无法使用，因为它不共享数据。更多信息见 HUD 和准星。

我的 FPS 没有显示

在 选项 → 你的电脑 中开启测量。第一次使用时，GameHub 会下载 PresentMon，并可能请求读取 Windows 性能数据的权限（需要注销并重新登录一次）。

会和反作弊产生问题吗？

GameHub 不会进入任何游戏内部：它从外部测量 FPS，HUD 和准星是位于游戏上方的透明窗口。即便如此，在锦标赛和部分竞技比赛中，其规则可能禁止使用外部准星。

会上架 Microsoft Store 吗？

会的，很快。在此之前，可以从本网站下载，它会自动更新。

支持 Steam Deck 或 Linux 吗？

暂时不支持：目前仅支持 Windows。Linux 和 Steam Deck 版本正在开发中；见更新内容。

有中文版吗？

有。GameHub 提供简体中文、英语和西班牙语界面，并会自动选择 Windows 的语言。
