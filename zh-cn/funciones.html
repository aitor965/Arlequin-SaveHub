完整的游戏库集中在一处

Steam、Epic、GOG、Xbox、Ubisoft、EA、Battle.net、Amazon、Rockstar，以及没有启动器的游戏，全部在一起。

GameHub 会查看你电脑上已有的内容：每个商店启动器保存的文件夹和文件。这样它就能找到你已安装的游戏，以及你拥有但尚未安装的游戏，并附上封面和你的游戏时长。即使你从游戏自己的启动器打开游戏，时长也会被统计。

在侧边栏点击“游戏库”，会显示你的各个商店以及每个商店中的游戏数量（即使某个商店应用已安装但还没有游戏，也会显示）。你可以按名称、最近游玩、时长或大小排序，即时搜索，并查看最近玩过的游戏。

没有启动器的游戏（模拟器、itch.io 游戏……）可以通过“添加游戏”按钮添加，或者告诉 GameHub 你存放独立游戏的文件夹，它会自动找到。它也会为其他商店的游戏、手动添加的游戏或已从商店下架的游戏查找 Steam 官方封面；如果没有，就使用游戏的图标，你也可以随时设置自己的图片。

你在多个商店或同一文件夹中拥有的同一款游戏只会显示一次。如果 Steam 正在更新某个游戏，你会在它的卡片上看到（“正在更新 45%”或“待更新”）。

如果混进了不是游戏的东西（程序、服务器……），移除它，GameHub 就会学习。你可以在 选项 → 游戏库 中恢复。

它从不索要任何商店的密码：开始游戏时，它会用各自的启动器打开每个游戏，就像你自己打开一样。

使用方法

  • 打开它并等待几秒钟：你的游戏会自动出现。
  • 双击或点击“开始游戏”按钮（封面下方）即可打开游戏。
  • “显示 N 款未安装的游戏”会同时显示你未安装的游戏。
  • “查找游戏”会立即重新检查你的商店。

游戏详情页

关于一个游戏的一切都在一个面板中：它在你电脑上的运行情况、你的 FPS、你的设置和你的存档。

点击一个游戏会打开它的详情页，分为三个标签页：概览（你的游戏时长、上次游玩时间、占用空间、配置要求、你的 FPS 和画面设置）、已保存的存档和信息（你的成就、简介、商店、开发商、发行日期、安装位置和存档位置）。

我的电脑能跑吗？GameHub 了解你的处理器、显卡和内存，并将它们与 Steam 商店中每个游戏的最低和推荐配置进行比较。你会看到一个红绿灯：绿色表示运行绰绰有余，黄色表示满足最低配置，红色表示达不到。在游戏库中，你可以筛选只看运行绰绰有余的、可运行的或无法运行的游戏。

还能看到你能跑多少 FPS，带有范围（“≈ 75 FPS（65-85）”），并分为各个画质：低、中、高和极致。如果你已经玩过，会优先显示你的真实 FPS（仅限当前显卡和处理器的数据）；如果没有，则根据社区的游戏数据计算（如果你分享自己的数据或拥有 ArlequinPro），或者根据 Steam 配置要求进行近似估算。

瓶颈在哪里，升级什么最值得？GameHub 会分别计算你的显卡能提供的帧数和你的处理器能支撑的帧数，并清楚地告诉你：“瓶颈在显卡：更好的处理器几乎不会提升 FPS”，或者反过来，或者两者旗鼓相当，需要同时升级。

它还会分组显示该游戏的存档（存档、设置……）、备份，以及打开其文件夹或安装它的按钮。

使用方法

  • 在游戏库中点击任意游戏，然后在顶部切换标签页。
  • 游戏库顶部栏中的“在我的电脑上”筛选。

更改每个游戏的画面设置

画质、分辨率、显示模式、FPS 上限、垂直同步……在 GameHub 中即可设置，无需打开游戏。

GameHub 会读取每个游戏保存的画面设置，并显示在它的详情页中。对于以已知格式保存设置的游戏，你还可以更改它们：主要设置（整体画质、分辨率、显示模式、FPS 上限和垂直同步）就在页面上，“所有设置”会打开一个窗口，分组列出全部设置并带有搜索框。

它支持使用 Unreal Engine（Borderlands 3 和 4、Hogwarts Legacy、THE FINALS……）、Unreal Engine 3（Rocket League、Killing Floor 2……）、Unity 和 Source（Counter-Strike 2……）制作的游戏，以及 GTA V（传承版和增强版）、Cyberpunk 2077 和 Far Cry 2 至 6。

第一次更改前，它会保存一份原始设置的副本：点击“恢复原始设置”即可恢复原样。游戏运行时它不允许更改任何内容（否则游戏退出时会覆盖），并且会尊重只读文件。

使用方法

  • 在游戏详情页中找到“你的画面设置”。
  • 随意更改并点击“保存”：下次打开游戏时生效。

你的真实 FPS

在你游戏时测量 FPS，不触碰游戏，并告诉你瓶颈在哪里。

借助 Intel 的免费开源工具 PresentMon，GameHub 从外部观察游戏绘制每一帧的时间：它不会注入任何东西，因此不会干扰反作弊。关闭游戏时，它会保存一份摘要：平均 FPS、中位数、1% Low（衡量流畅度）和卡顿。

它会记录该局游戏的画面设置（画质、分辨率、DLSS/FSR、帧生成、光线追踪、垂直同步、FPS 上限），并告诉你性能的瓶颈：显卡、处理器还是 FPS 上限（如果你被垂直同步或游戏/驱动的上限限制了，会显示“已限制”，而不会错怪处理器）。另外还会显示游戏使用的内存、显存和虚拟内存，以防你资源不足。

我们验证过它的测量是准确的：对于一个恰好以 360 FPS 运行的动画，GameHub 测得 358.8。如果你想在游戏时看到它们，可以放到 HUD 上。

使用方法

  • 在欢迎界面或 选项 → 你的电脑 中开启（可选）。Windows 会请求一次权限，在你注销或重启后开始测量。
  • 玩一会儿然后关闭游戏：你会在它的详情页“你的 FPS”中看到结果。
🖥️

你的电脑一目了然

你的配置、你的网络，以及还需要开启什么才能发挥最大性能。

GameHub 会显示你的处理器、显卡、内存（频率、时序和模块）、磁盘、显示器及其刷新率、键盘和鼠标，以及通过约 25 秒的测试得出的网速。

它还会提醒你那些经常被忽略而没有开启的设置：如果因为 BIOS 中没有开启 XMP 配置文件（AMD DDR5 上为 EXPO），你的内存运行速度低于包装上标注的速度；或者你的电脑支持 Resizable BAR（AMD 上为 Smart Access Memory）但它处于关闭状态。这两项在很多游戏中都能免费带来额外的 FPS，它还会告诉你它们在各品牌 BIOS 中的名称。

使用方法

  • 选项 → 你的电脑。
  • 点击“测试网速”进行网络测试（每月一次的自动测试在使用移动数据时不会进行）。

Play Hub：在沙发上玩

专为手柄和电视打造的全屏界面。

按 F11 或从侧边栏进入，GameHub 会变成一个适合用手柄操作的大界面：超大封面，选中的游戏及其信息显示在背景中，逐个平滑移动。

顶部有标签页：“全部”以及每个商店各一个。用 L1/R1（Xbox 上为 LB/RB）切换标签页，每个标签页都有自己的行：继续游戏、玩得最多和你的整个游戏库。回到某个标签页时，你会停留在上次离开的位置。

它能识别 Xbox、PlayStation 和 Switch 手柄，并根据你使用的手柄（或你选择的样式）更改屏幕上显示的按钮。它也支持键盘（方向键、WASD、Q/E）和鼠标滚轮。没有封面的游戏会获得一个专属封面，带有其名称和配色。

使用方法

  • 按 F11 或点击侧边栏中的“Play Hub”。
  • 在 选项 → 手柄和 Play Hub 中选择按钮样式。

内置聊天

Discord、Steam 聊天和 TeamSpeak 就在你的游戏旁边。

在 GameHub 内打开各个服务的聊天，面板宽度可以随意调整，也可以弹出到单独的窗口。每个服务可以单独开关，并有各自的声音；使用 TeamSpeak 时，你能看到频道里谁在说话。

此外，你的 Discord 状态会显示“Arlequin GameHub”以及你正在玩的游戏和已玩时间（可以在 选项 → 游戏时 中关闭）。

游戏时，即使 GameHub 关闭窗口把资源全部留给游戏，聊天也可以保持连接：在 选项 → 游戏时 中选择。

使用方法

  • 点击侧边栏中的“聊天”并选择服务。
  • 在 选项 → 聊天 中选择服务和声音。
🎁

幸运宝箱

不知道玩什么？交给运气吧。

一个类似游戏内战利品箱的转盘，会从你的游戏中挑选一款。你可以选择已安装或未安装的游戏、来自哪个商店，以及按游戏时长还是按成就来抽：从未打开过的游戏最容易抽中，玩得最多的则最稀有。

每天可以抽 5 次（使用 ArlequinPro 无限次）。

使用方法

  • 在侧边栏中点击“幸运宝箱”。
🥔

POTATO MODE

适合配置较低的电脑：在超轻量原生窗口中运行的 GameHub。

POTATO MODE 会以不带网页界面（内部不含浏览器）的方式重启 GameHub：只有你的游戏和一个开始按钮。它占用的内存少得多，并且仍会备份你的存档、统计你的游戏时长。

POTATO MODE+（ArlequinPro）更进一步：只保留启动器，后台不运行任何东西，整台电脑都留给游戏。

使用方法

  • 侧边栏中的“POTATO MODE”按钮（“+”为 POTATO MODE+）。
  • 在 选项 → 性能 中可以设置始终以此模式启动，并选择哪一种。
  • 打开游戏时，GameHub 会自动切换到 POTATO MODE（关闭其窗口和聊天，把资源全部留给游戏），关闭游戏后恢复原样。在 选项 → 游戏时 中可以选择是否关闭窗口以及是否断开聊天（例如，为了保持在 Discord 通话中）。
🎨

随心定制

主题、语言以及 GameHub 的行为方式。

选择一个主题（Arlequin、午夜、纯黑的深色或白色背景的浅色；使用 ArlequinPro 还有日落和霓虹），界面支持英语和西班牙语（简体中文将随下一个稳定版本推出）。对于配置较低的电脑，有轻量模式，可关闭动画、透明和光效（在欢迎界面就可以开启）。

GameHub 可以随 Windows 启动并隐藏在系统托盘中（即使你从其他启动器开始游戏，也能统计时长并备份存档）。它会自动更新（如果你跳过了几个版本，会把所有新内容一起展示给你），第一次使用时会按商店列出你的游戏，方便你移除不是游戏的项目。

使用方法

  • 选项：每个页面顶部都会说明你可以在其中设置什么。
