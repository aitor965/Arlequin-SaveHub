POTATO MODE

リソースが少ないPC向け。GameHubを超軽量のネイティブウィンドウで動かします。

POTATO MODE は、GameHub をウェブインターフェース(内蔵ブラウザ)なしで再起動します。表示されるのはゲームとプレイボタンだけ。メモリ使用量が大幅に減り、セーブのバックアップとプレイ時間のカウントも続けます。

POTATO MODE+(ArlequinPro)はさらに軽く、ランチャーだけでバックグラウンド処理もありません。PC のすべてをゲームに使えます。

POTATO MODE のウィンドウは、グラフィックカードを使わず CPU で描画されます。GameHub の使用量は合計で約 66 MB のメモリ(通常モードでは 440 MB)で、ビデオメモリは使いません。通常のインターフェースも、特にゲームが多いときや GameHub を最小化しているときに、以前よりメモリと GPU の使用量が大幅に減りました。

使い方

  • サイドバーの「POTATO MODE」ボタン(POTATO MODE+ は「+」)。
  • オプション → パフォーマンスで、常にこのモードで起動するように設定し、どちらのモードにするか選べます。
  • ゲームを開くと、GameHub は自動的に POTATO MODE に切り替わり(ウィンドウとチャットを閉じてすべてをゲームに譲ります)、ゲームを閉じると元の状態に戻ります。オプション → プレイ時で、ウィンドウを閉じるかどうか、チャットを切断するかどうか(たとえば Discord 通話を続けたい場合など)を選べます。
  • ゲームを閉じるとすぐに GameHub が戻ります。ゲームを開いたときの POTATO MODE への切り替えは、オプション → パフォーマンスでオフにできます。
