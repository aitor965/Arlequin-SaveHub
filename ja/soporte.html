✦ インストール

1分で準備完了

ダウンロード

このウェブサイトからArlequin-GameHub-Setup.exeをダウンロードするか、Microsoft Storeからインストールしてください。

開く

まだ署名されていないため、Windowsが警告を表示する場合があります。詳細情報 → 実行をクリックしてください。

リストを確認

初回は、見つかったゲームがストアごとに表示されるので、ゲームではないものがあれば削除できます。

プレイ

セーブデータのバックアップ先を選び、必要ならクラウドを接続してください。それ以降は自動で更新されます。

動作環境:64ビット版のWindows 10または11。アンインストールは、Windowsの設定 → アプリ → Arlequin GameHubから行えます。セーブデータのバックアップは、そのフォルダーに残ります。

✦ よくある質問

よく聞かれること

本当に無料ですか?

はい。ArlequinFreeはずっと無料で、広告もありません。ArlequinProは、公開されたあともオプションです。違いはFreeとProをご覧ください。

SteamやEpicなどのパスワードを聞かれますか?

いいえ、決して聞きません。GameHubは、PCにすでにあるゲームを読み取り、各ゲームをそれぞれのランチャーで起動します。クラウドについては、Google、Microsoft、Dropboxの公式ページでサインインするので、GameHubがパスワードを見ることはありません。

Windowsに「認識されないプログラム」と表示されます

GameHubがまだ署名されていない間は正常な動作です。詳細情報 → 実行をクリックしてください。

ゲームが見つからないのはなぜですか?

「ゲームを検索」をクリックして、ストアをもう一度確認させてください。ランチャーのないゲームの場合は、「ゲームを追加」で追加するか、オプション → ライブラリで、バラバラのゲームが入っているフォルダーを指定してください。

ゲームのセーブデータが見つからないのはなぜですか?

データベースはまだ始まったばかりです。ゲームのページでフォルダーを手動で追加するか、そのままプレイしてください。GameHubが保存場所を学習し、共有をオンにしていれば、そのゲームは他の人のPCでも自動で見つかるようになります。

どんなデータを収集しますか?

「Arlequinの改善に協力」をオンにしている場合のみ、セーブの保存先、PCのハードウェア、FPSを測定している場合はセッションの概要を、常に匿名で収集します。オプション → プライバシーとデータで、共有する内容を選べます。すべてプライバシーポリシーに記載しています。

ゲームでHUDやクロスヘアが表示されません

ゲームをボーダーレス/ウィンドウ化フルスクリーン、またはボーダーレスウィンドウに設定してください(排他的フルスクリーンでは表示されません)。そのゲームでオンになっていることと、Ctrl+Alt+HやCtrl+Alt+Xで非表示にしていないことも確認してください。

HUDの温度が「—」と表示されます

このデータには、センサープログラムを開いておく必要があります。HWiNFO(「Shared Memory Support」付き。無料版では12時間ごとにオフになります)、LibreHardwareMonitor(Remote Web Server付き)、MSI Afterburnerが使えます。HWMonitorは、データを共有しないため使えません。詳しくはHUDとクロスヘアをご覧ください。

FPSが表示されません

オプション → あなたのPCで測定をオンにしてください。初回は、GameHubがPresentMonをダウンロードし、Windowsのパフォーマンスデータを読み取る許可を求める場合があります(一度サインアウトして再度サインインが必要です)。

アンチチートと問題を起こしませんか?

GameHubはゲームの中には入り込みません。FPSは外部から測定し、HUDとクロスヘアはゲームの上に重ねる透明なウィンドウです。それでも、大会や一部の対戦では、ルールで外部クロスヘアが禁止されている場合があります。

Microsoft Storeにありますか?

はい。Microsoft Storeで配信中です。同じプログラムですが、新機能や改善はこのウェブサイトの版が先に届きます。Microsoftが各バージョンを審査してから公開するため、Store版は少し遅れる場合があります。Store版はStoreが更新し、このウェブサイトの版は自動で更新されます。

Steam DeckやLinuxで動きますか?

ホームページにLinux向けのテスト版(64ビットAppImage)があります。Nobaraでのみテストしているため、他のディストリビューションでは動かない場合があり、まだ自動更新には対応していません。Steam Deckはまだテストしていません。

自分の言語で使えますか?

GameHubは英語、スペイン語、簡体字中国語、ロシア語、ポルトガル語(ブラジル)、ドイツ語、フランス語、イタリア語に対応しており、ベータ版では日本語とポーランド語にも対応しています。言語はWindowsの設定から自動で選ばれます。今後も言語を増やしていきます。
