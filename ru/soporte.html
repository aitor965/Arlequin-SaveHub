✦ Установка

Готово за минуту

Скачайте

Arlequin-GameHub-Setup.exe с официальной страницы релизов на GitHub или установите из Microsoft Store.

Откройте

Поскольку программа пока без подписи, Windows может предупредить: нажмите Подробнее → Выполнить в любом случае.

Проверьте список

В первый раз он покажет найденные игры по магазинам, чтобы вы убрали то, что не игра.

Играйте

Выберите, где хранить копии сохранений, и, если хотите, подключите облако. Дальше он обновляется сам.

Требования: Windows 10 или 11 (64 бита). Чтобы удалить: Параметры Windows → Приложения → Arlequin GameHub. Копии сохранений остаются в своей папке.

✦ Вопросы

Что обычно спрашивают

Это правда бесплатно?

Да. ArlequinFree бесплатен навсегда и без рекламы. ArlequinPro, когда выйдет, будет необязательным. Разницу смотрите в Free и Pro.

Он спрашивает пароли от Steam, Epic…?

Нет, никогда. GameHub читает игры, которые уже есть на вашем ПК, и запускает каждую через её лаунчер. Для облака вы входите на официальной странице Google, Microsoft или Dropbox, и GameHub не видит ваш пароль.

Windows пишет, что программа не распознана

Это нормально, пока GameHub не подписан. Нажмите Подробнее → Выполнить в любом случае.

Почему он не находит игру?

Нажмите «Найти игры», чтобы он заново проверил магазины. Если это игра без лаунчера, добавьте её через «Добавить игру» или укажите в Настройки → Библиотека папку с отдельными играми.

Почему он не находит сохранения игры?

База данных только начинает расти. Можно добавить папку вручную на странице игры или просто играть: GameHub узнает, куда она сохраняет, и, если вы делитесь, эта игра будет находиться сама на ПК других людей.

Какие данные он собирает?

Только если вы оставите «Помочь улучшить Arlequin» включённым: пути сохранений, железо вашего ПК и, если вы измеряете FPS, сводку ваших сессий — всегда анонимно. В Настройки → Конфиденциальность и данные вы выбираете, чем делиться. Всё описано в политике конфиденциальности.

HUD или прицел не видны в игре

Переведите игру в оконный полноэкранный режим без рамки или в окно без рамки (в эксклюзивном полноэкранном они не видны), проверьте, что они включены для этой игры и что вы не скрыли их через Ctrl+Alt+H или Ctrl+Alt+X.

HUD показывает «—» вместо температур

Для этих данных нужна открытая программа мониторинга: HWiNFO (с «Shared Memory Support», который в бесплатной версии отключается каждые 12 часов), LibreHardwareMonitor (с его Remote Web Server) или MSI Afterburner. HWMonitor не работает, потому что не делится данными. Подробнее — в HUD и прицел.

Мой FPS не показывается

Включите измерение в Настройки → Ваш ПК. В первый раз GameHub скачает PresentMon и может попросить разрешение читать данные производительности Windows (один раз нужно выйти из системы и войти снова).

Не будет ли проблем с античитами?

GameHub не вмешивается ни в одну игру: FPS измеряется снаружи, а HUD и прицел — прозрачные окна поверх игры. Тем не менее на турнирах и в некоторых соревновательных матчах сторонние прицелы могут быть запрещены правилами.

Он есть в Microsoft Store?

Да: он уже есть в Microsoft Store. Это та же программа, но версия с этого сайта первой получает новые функции и улучшения: версия из Store может получать их чуть позже, потому что Microsoft проверяет каждую версию перед выпуском. Версию из Store обновляет Store, а версия с этого сайта обновляется сама.

Работает ли на Steam Deck или Linux?

Пока нет: сейчас только Windows. Linux и Steam Deck на подходе; см. Новости.

Есть ли он на моём языке?

GameHub есть на английском, испанском и упрощённом китайском, а в бете — ещё на русском, португальском (Бразилия), немецком, французском и итальянском; он выбирает язык Windows.
