POTATO MODE

Para PCs com poucos recursos: o GameHub em uma janela nativa ultraleve.

O POTATO MODE reinicia o GameHub sem a interface web (sem navegador dentro): só seus jogos e um botão para jogar. Usa bem menos memória e continua fazendo backup dos saves e contando suas horas.

O POTATO MODE+ (ArlequinPro) vai ainda mais longe: só o launcher, sem nada em segundo plano, para que todo o seu PC fique para o jogo.

A janela do POTATO MODE é desenhada pelo processador, sem usar a placa de vídeo: usa uns 10 MB de memória e nada de memória de vídeo. E a interface normal também usa bem menos memória e GPU do que antes, principalmente com muitos jogos ou com o GameHub minimizado.

Como usar

  • O botão “POTATO MODE” na barra lateral (e “+” para o POTATO MODE+).
  • Em Opções → Desempenho você pode fazer com que ele sempre inicie assim e escolher qual.
  • Quando você abre um jogo, o GameHub passa sozinho para o POTATO MODE (fecha a janela e o chat para deixar tudo para o jogo) e volta como estava quando você o fecha. Em Opções → Ao jogar você escolhe se ele fecha a janela e se desconecta o chat (por exemplo, para continuar em uma chamada do Discord).
  • O GameHub volta assim que você fecha o jogo, e entrar no POTATO MODE ao abrir um jogo pode ser desativado em Opções → Desempenho.
