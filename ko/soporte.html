✦ 설치

1분이면 준비 끝

다운로드

이 웹사이트의 Arlequin-GameHub-Setup.exe를 받거나 Microsoft Store에서 설치하세요.

실행

아직 서명되지 않았기 때문에 Windows가 경고를 표시할 수 있습니다. 추가 정보 → 실행을 클릭하세요.

목록 확인

처음 실행하면 찾은 게임이 스토어별로 표시되므로, 게임이 아닌 항목은 제거할 수 있습니다.

플레이

세이브 백업을 보관할 위치를 선택하고, 원하면 클라우드를 연결하세요. 그 후에는 알아서 업데이트됩니다.

요구 사항: 64비트 Windows 10 또는 11. 제거하려면 Windows 설정 → 앱 → Arlequin GameHub로 이동하세요. 세이브 백업은 해당 폴더에 그대로 남습니다.

✦ FAQ

자주 묻는 질문

정말 무료인가요?

네. ArlequinFree는 광고 없이 영원히 무료입니다. ArlequinPro는 출시되더라도 선택 사항입니다. 차이는 Free와 Pro에서 확인하세요.

Steam, Epic 등의 비밀번호를 요구하나요?

아니요, 절대 요구하지 않습니다. GameHub는 이미 PC에 있는 게임을 읽고 각 게임을 해당 런처로 실행합니다. 클라우드는 Google, Microsoft, Dropbox의 공식 페이지에서 로그인하며, GameHub는 비밀번호를 볼 수 없습니다.

Windows에서 프로그램을 인식할 수 없다고 합니다

GameHub가 아직 서명되지 않은 동안에는 정상입니다. 추가 정보 → 실행을 클릭하세요.

게임을 찾지 못하는 이유는 무엇인가요?

“게임 찾기”를 클릭하면 스토어를 다시 확인합니다. 런처가 없는 게임이라면 “게임 추가”로 추가하거나, 옵션 → 라이브러리에서 개별 게임이 들어 있는 폴더를 알려 주세요.

게임의 세이브를 찾지 못하는 이유는 무엇인가요?

데이터베이스가 이제 막 시작 단계입니다. 게임 페이지에서 폴더를 직접 추가하거나 그냥 플레이하세요. GameHub가 세이브 위치를 배우고, 공유를 켜 두면 그 게임을 다른 사람의 PC에서도 자동으로 찾을 수 있게 됩니다.

어떤 데이터를 수집하나요?

“Arlequin 개선에 참여”를 켜 둔 경우에만 세이브 경로, PC 하드웨어, 그리고 FPS를 측정한다면 세션 요약을 수집하며, 항상 익명입니다. 옵션 → 개인정보 및 데이터에서 공유할 항목을 선택합니다. 모든 내용은 개인정보 처리방침에 있습니다.

게임에서 HUD나 크로스헤어가 표시되지 않습니다

게임을 테두리 없는 전체 화면/창 모드 또는 테두리 없는 창으로 설정하세요(독점 전체 화면에서는 표시되지 않습니다). 해당 게임에서 켜져 있는지, 그리고 Ctrl+Alt+H 또는 Ctrl+Alt+X로 숨기지 않았는지 확인하세요.

HUD에 온도가 “—”로 표시됩니다

이 데이터는 센서 프로그램이 열려 있어야 합니다. HWiNFO(“공유 메모리 지원” 사용, 무료 버전에서는 12시간마다 꺼짐), LibreHardwareMonitor(원격 웹 서버 사용), MSI Afterburner 중 하나입니다. HWMonitor는 데이터를 공유하지 않으므로 작동하지 않습니다. 자세한 내용은 HUD와 크로스헤어를 참고하세요.

FPS가 표시되지 않습니다

옵션 → 내 PC에서 측정을 켜세요. 처음에는 GameHub가 PresentMon을 내려받고 Windows 성능 데이터를 읽을 권한을 요청할 수 있습니다(한 번 로그아웃했다가 다시 로그인해야 합니다).

안티치트와 문제를 일으키나요?

GameHub는 어떤 게임에도 들어가지 않습니다. FPS는 외부에서 측정하며, HUD와 크로스헤어는 게임 위에 올라가는 투명한 창입니다. 그래도 대회나 일부 경쟁 매치에서는 규정에 따라 외부 크로스헤어가 금지될 수 있습니다.

Microsoft Store에 있나요?

네. 이제 Microsoft Store에서 받을 수 있습니다. 같은 프로그램이지만 이 웹사이트의 버전이 새 기능과 개선 사항을 먼저 받습니다. Microsoft가 각 버전을 검토한 뒤 배포하므로 Store 버전은 조금 늦을 수 있습니다. Store 버전은 Store가 업데이트하고, 이 웹사이트의 버전은 스스로 업데이트합니다.

Steam Deck이나 Linux에서 작동하나요?

홈페이지에 Linux용 테스트 버전(64비트 AppImage)이 있습니다. Nobara에서만 테스트했으므로 다른 배포판에서는 실패할 수 있고 아직 스스로 업데이트하지 않습니다. Steam Deck은 아직 테스트하지 않았습니다.

내 언어로 사용할 수 있나요?

GameHub는 영어, 스페인어, 중국어 간체, 러시아어, 포르투갈어(브라질), 독일어, 프랑스어, 이탈리아어로 제공되며, 베타에서는 일본어와 폴란드어도 지원합니다. Windows의 언어를 따라갑니다. 더 많은 언어가 추가될 예정입니다.
