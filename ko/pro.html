✦ 무료와 PRO

영원히 무료

GameHub의 중요한 기능은 절대 유료가 되지 않습니다. ArlequinPro는 더 많은 기능을 원하는 분들을 위한 선택 사항입니다.

ArlequinFree

중요한 기능은 모두 무료이며 계정도 필요 없습니다.
  • 모든 스토어의 게임을 한곳에 모은 라이브러리
  • 게임을 닫을 때마다 세이브 백업
  • 손상된 세이브 방지
  • 게임당 백업 3개, PC 1대에서 클라우드로 백업
  • HUD, 크로스헤어, 커넥터 감시
  • 그래픽 설정, 내 PC에서 실행 가능?, 내 FPS
  • 채팅, Play Hub, 컨트롤러, POTATO MODE
  • 내 요약, BenchHub, AimHub, LootHub, DiskHub, ShopHub, SocialHub, FixHub
  • ReplayHub: 클립 녹화 및 시청(최대 2분, 모든 게임)
  • EmuHub: 에뮬레이터와 콘솔 게임을 라이브러리에서
  • TVHub와 RemoteHub: TV에서 플레이하고 휴대폰을 게임패드, 마우스, 키보드로 사용

ArlequinPro 개발 중

Free의 모든 기능에 더해:
  • 게임당 최대 10개 백업, 플레이 중 백업
  • 세이브 슬롯: 세이브가 하나뿐인 게임에서 여러 세이브 사용
  • 시간 되돌리기: 원하는 날짜와 시간의 세이브 복구
  • 모든 PC에서 세이브 동기화
  • 게임별 프로필: HUD, 크로스헤어, POTATO MODE, ReplayHub, 그래픽 설정이 게임 실행 시 적용
  • 그래픽 설정 프로필: “경쟁용”, “화려하게”… 한 번의 클릭으로
  • 게임 중 온도 경고, 플레이 종료 후 리포트, 주간 요약
  • 추정 FPS와 커뮤니티 통계, 항상 제공
  • HUD와 크로스헤어를 공유하는 코드 만들기
  • HUD 스타일: 템플릿, 글꼴, 모서리
  • POTATO MODE+: 런처만 남기고, 계속 실행할 것은 직접 선택
  • ReplayHub: 최대 2시간 클립, 트랙 분리, 클립 편집, “항상 녹화”
  • Streams: 여러 플랫폼과 채팅 동시 사용, 여러 카메라, “잠시 후 돌아옵니다” 워터마크 없음
  • RemoteHub: 휴대폰으로 라이브 방송 제어와 나만의 버튼 (Stream Deck처럼)
  • EmuHub: 자동 세이브 스테이트
  • Hall of Fame에서 다른 플레이어의 설정 복사
  • AimHub: 설정 복사와 60일간의 “내 성장”
  • 게임별 FPS 기록: 드라이버나 설정을 바꾸기 전후를 1% 로우와 함께
  • 센서 세션: 온도, 소비 전력, FPS를 1초 단위로 기록하고 그래프로 보고 CSV로 내보내기
  • 내 PC 건강: 온도와 하드웨어 오류(WHEA) 기록, 알림 포함
  • BenchHub: 전체 기록(최대 300회 테스트)과 최대 8개 동시 비교
  • 세이브를 다른 디스크, USB 메모리, 네트워크 드라이브에 한 번 더 복사
  • 더 많은 테마와 배경: Arlequin 마름모, 그라데이션, 직접 고른 색
  • “내 PC”의 시뮬레이터: 다른 그래픽카드로 FPS가 얼마나 오를지, RAM을 늘리면 끊김이 줄어드는지
  • 하루 5회 돌릴 수 있는 행운 상자와 추가 테마
