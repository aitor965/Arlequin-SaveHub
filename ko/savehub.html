✦ SAVEHUB

내 세이브, 언제나 안전하게

SaveHub는 GameHub에서 세이브를 지켜 주는 기능입니다. 게임을 닫을 때마다 세이브를 백업하고, 내 PC 또는 내 클라우드에서 한 번의 클릭으로 되돌릴 수 있습니다.

💾

자동 백업

게임을 닫을 때마다 GameHub가 세이브를 백업합니다. 기억할 필요가 없습니다.

게임을 닫으면 GameHub는 선택한 폴더(다른 드라이브나 이미 클라우드와 동기화 중인 폴더가 좋습니다)에 세이브를 압축 백업합니다. 게임 설정(그래픽, 조작, 키)과 일부 게임이 Windows 레지스트리에 보관하는 세이브도 백업할 수 있습니다.

로그나 캐시(예: 많은 게임이 만드는 셰이더 캐시)는 절대 백업하지 않습니다. 중요한 것만 백업합니다.

몇 시간씩 켜 두는 게임(MMO, 생존 게임 등)은 ArlequinPro에서 플레이 중에도 15분, 30분, 60분마다 백업할 수 있습니다.

게임마다 “자동” 스위치가 있고 세이브 폴더마다 “복사” 스위치가 있습니다. 게임의 세이브가 250 MB를 넘으면 알려 주며 백업할지는 직접 정합니다. 백업을 고정하면 절대 삭제되지 않습니다.

직접 다운로드 버전 전용 EmuHub 콘솔 게임의 세이브와 세이브 스테이트도 백업하며, ArlequinPro에서는 자동 세이브 스테이트를 만듭니다.

사용 방법

  • 알아서 작동하며 따로 설정할 것은 없습니다.
  • 게임 페이지의 “지금 백업”을 누르면 바로 백업합니다.
  • SaveHub의 “전체 백업”은 모든 게임을 백업합니다.
🛡️

손상된 세이브 방지

백업이 잘못되어도 정상 백업은 사라지지 않습니다.

자동 백업이 이전 것보다 훨씬 작게 만들어지면(예: 게임이 비정상 종료되었거나 세이브가 손상된 경우) GameHub는 기존의 정상 백업을 삭제하지 않고 새 백업과 함께 보관합니다.

게임당 여러 백업을 보관합니다(ArlequinFree는 3개, ArlequinPro는 기본 5개에서 최대 10개). 한도를 넘으면 가장 오래된 것이 삭제됩니다.

사용 방법

  • 기본으로 켜져 있습니다. 옵션 → SaveHub에서 변경할 수 있습니다.
  • GameHub는 게임이 비정상 종료(멈춤이나 충돌)되었는지 알아채고, 해당 백업에 표시를 하고, 되돌릴 수 있도록 이전 백업을 고정합니다. 게임을 닫을 때 세이브가 괜찮은지 묻고, 괜찮지 않다고 하면 이전 백업을 복원합니다.
  • SaveHub는 이번 달에 플레이했지만 최신 세이브의 백업이 없는 게임을 «지금 백업»과 함께 알려 줍니다.
↩️

복원하고 백업을 가지고 다니기

한 번의 클릭으로 원하는 백업으로 되돌리거나 USB 메모리로 옮깁니다.

각 게임 페이지에서 백업 목록(언제, 왜 만들어졌는지: 게임을 닫을 때, 수동 등)을 보고 원하는 백업을 복원할 수 있습니다. 복원하기 전에 GameHub는 현재 상태를 보관하므로 실수해도 되돌릴 수 있습니다.

“복사 위치…”로 모든 백업, 각 게임의 최신 백업, 런처가 없는 게임의 백업, 특정 게임의 백업을 다른 폴더나 USB 메모리로 옮길 수 있습니다.

복원 도중 문제가 생기면 GameHub가 작업을 취소하고 세이브를 원래대로 둡니다.

복원하기 전에 GameHub는 백업이 완전한지 확인합니다. 손상되었다면 아무것도 건드리지 않습니다.

사용 방법

  • 게임 페이지 → 세이브 파일 → 복원.
  • SaveHub → “복사 위치…”.
🗂️

세이브 슬롯

세이브가 하나뿐인 게임에서 여러 세이브를 사용합니다. ArlequinPro 전용.

일부 게임은 세이브가 하나뿐이라서, 처음부터 다시 하거나 다른 사람이 내 PC에서 플레이하면 내 세이브를 잃게 됩니다. 세이브 슬롯을 쓰면 게임당 최대 10개의 세이브를 만들고 한 번의 클릭으로 전환할 수 있습니다.

새 슬롯은 처음부터 시작하거나 사용 중인 세이브의 복사본으로 시작할 수 있습니다. 전환할 때 GameHub는 먼저 현재 세이브를 해당 슬롯에 저장하고 이상이 없는지 확인하며, 문제가 있으면 모든 것을 원래대로 둡니다. 게임 설정은 바뀌지 않습니다.

클라우드를 연결하면 슬롯도 클라우드에 저장되어 모든 PC에서 사용할 수 있습니다.

사용 방법

  • 게임 페이지 → 세이브 파일 → 세이브 슬롯.
  • 게임을 닫은 상태에서 “슬롯 2”를 클릭하고 시작 방식을 선택하세요.
☁️

내 클라우드의 세이브

Google Drive, OneDrive, Dropbox를 연결해 세이브를 다른 PC로 가져가세요.

각 백업은 클라우드의 GameHub 폴더에 업로드되며, 나머지 파일은 건드리지 않습니다. 백업을 다른 PC로 가져오면 Windows 사용자 이름이 다르거나 게임이 다른 드라이브에 있어도 GameHub가 해당 PC에 맞게 조정합니다.

ArlequinFree에서는 PC 1대에서 백업이 클라우드로 업로드되며(PC를 바꾸면 30일에 한 번 새 PC로 옮길 수 있음), 어느 PC에서든 클라우드에 있는 내용을 보고 백업을 직접 복원할 수 있습니다. ArlequinPro에서는 모든 PC에서 세이브가 자동으로 동기화되고, 다른 PC에 더 최신 세이브가 있으면 GameHub가 알려 줍니다.

클라우드는 사용자의 것입니다. Arlequin은 세이브를 자체 서버에 보관하지 않습니다. 각 서비스의 공식 페이지에서 로그인하며, GameHub는 비밀번호를 볼 수 없습니다.

사용 방법

  • SaveHub에서 Google Drive, OneDrive, Dropbox 중 하나를 클릭하고 로그인하세요.
  • 그 후에는 모든 백업이 자동으로 업로드됩니다.
  • 두 PC가 동시에 업로드해도 더 이상 서로 덮어쓰지 않으며, 클라우드가 가득 찼거나 세션이 만료되면 분명하게 알려 줍니다.
🔎

게임별 세이브 위치를 알고 있습니다

모르는 것은 플레이하는 동안 배웁니다.

게임마다 세이브를 두는 곳이 다릅니다(문서, AppData, 게임 폴더, 레지스트리 등). GameHub는 스토어가 PC에 보관하는 정보(예: Steam의 클라우드 규칙)와 커뮤니티 데이터베이스를 통해 이를 알고 있습니다.

모르는 경우에는 플레이하는 동안 게임이 기록하는 파일을 지켜보고 세이브 폴더를 알아냅니다. 여러 게임이 함께 쓰는 폴더(예: Call of Duty)도 감지해서 세이브가 섞이지 않게 합니다. 폴더는 언제든 직접 추가할 수 있습니다.

게임 엔진(Unity, Unreal, Ren'Py, RPG Maker, GameMaker, Godot)과 스토어(GOG 클라우드, Xbox / Game Pass, Ubisoft Connect)를 기준으로 더 많은 세이브를 찾고, 자체 런처에서 실행되는 게임(예: GTA IV)도 이해하며, 다른 프로그램의 폴더나 Rockstar의 공유 폴더를 세이브로 착각하지 않습니다. 게임 페이지에서 각 폴더가 어디서 왔는지 알려 줍니다.

알려진 경로가 없는 게임은 이름과 설치 폴더 이름으로 일반적인 위치(My Games, 문서, 저장된 게임, AppData, 배급사 폴더 안 포함)에서 폴더를 찾고, 설정도 함께 찾습니다. 다른 프로그램의 폴더나 충돌 보고서·캐시만 있는 폴더는 가져가지 않습니다.

사용 방법

  • 게임 페이지 → 세이브 파일 → “폴더 추가”.
⚙️

내 취향대로

SaveHub의 모든 설정은 옵션 → SaveHub에서 합니다.

  • 백업 폴더(및 열기).
  • 게임을 닫을 때 백업하기, 설정 포함하기.
  • 손상된 세이브 방지.
  • 게임당 보관할 백업 수, 플레이 중 백업.
  • 압축: 빠름, 보통, 최대(공간은 적게 차지하고 시간은 조금 더 걸림).
  • “백업 제외”: 백업에 넣고 싶지 않은 파일이나 폴더(예: *.mp4 또는 Screenshots).

사용 방법

  • 옵션 → SaveHub.
